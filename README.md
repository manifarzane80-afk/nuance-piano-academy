# Nuance Piano Academy — سامانه مدیریت هنرجویان

پروژه‌ی واقعی Next.js (قابل اجرا و دیپلوی) برای مدیریت آموزشگاه پیانو، با:
- فرم ثبت‌نام چندمرحله‌ای هنرجو
- پنل استاد (شما، مانی فرزانه) با دسترسی کامل به همه‌چیز
- پنل جداگانه‌ی هر هنرجو (ورود با شماره موبایل + کد اختصاصی)
- دوزبانه (فارسی / English) و تم تیره/روشن، هر دو با یک دکمه در بالای صفحه
- دیتابیس: گوگل‌شیت شما (ساختار آماده برای مهاجرت بعدی به Supabase)

---

## ۱) نصب و اجرای محلی

```bash
npm install
cp .env.example .env.local
# مقادیر .env.local را طبق بخش‌های ۲ و ۳ همین فایل پر کنید
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

---

## ۲) ساخت اکانت ورود شما (استاد / همه‌کاره)

نیازی به ثبت‌نام نیست — اکانت شما مستقیماً در `.env.local` تعریف می‌شود:

```
TEACHER_PHONE=شماره موبایل شما
TEACHER_PASSWORD=یک رمز قوی انتخاب کنید
TEACHER_DISPLAY_NAME=مانی فرزانه
```

با همین شماره و رمز از صفحه‌ی `/login` وارد شوید. این اکانت به‌طور کامل:
- پنل استاد (`/teacher`) — مدیریت همه‌ی هنرجوها، جلسات، پیام‌ها، فایل‌ها
- پنل هنرجو (`/student`) — قابل مشاهده هم هست (برای تست تجربه‌ی هنرجو)

را می‌بیند. یعنی همان «ورود همه‌کاره»ای که خواسته بودید.

هنرجوها **نمی‌توانند** با این اطلاعات وارد شوند و فقط پنل خودشان را می‌بینند.

---

## ۳) اتصال گوگل‌شیت (دیتابیس)

### الف) ساخت سرویس‌اکانت گوگل
۱. به [Google Cloud Console](https://console.cloud.google.com) بروید و یک پروژه بسازید.
۲. از منوی APIs & Services → «Google Sheets API» را فعال کنید.
۳. از IAM & Admin → Service Accounts → یک سرویس‌اکانت جدید بسازید.
۴. برای آن سرویس‌اکانت یک کلید JSON بسازید و دانلود کنید.
۵. از داخل فایل JSON، مقدار `client_email` و `private_key` را در `.env.local` قرار دهید:

```
GOOGLE_SERVICE_ACCOUNT_EMAIL=xxx@xxx.iam.gserviceaccount.com
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
```

⚠️ کاراکترهای `\n` داخل کلید باید دقیقاً همان‌طور که در فایل JSON آمده باقی بمانند.

### ب) ساخت گوگل‌شیت
۱. یک Google Sheet خالی جدید بسازید.
۲. آن را با ایمیل سرویس‌اکانت (همان `client_email`) به‌عنوان **Editor** شیر کنید.
۳. از آدرس شیت، مقدار بین `/d/` و `/edit` را کپی کنید و در `.env.local` بگذارید:

```
GOOGLE_SHEET_ID=همین-مقدار
```

### ج) ساخت خودکار تب‌ها و ستون‌ها
به‌جای ساخت دستی، این دستور را اجرا کنید تا ۵ تب لازم (`Students`, `Sessions`,
`PracticeLogs`, `Messages`, `Files`) با هدرهای درست ساخته شوند:

```bash
node -r dotenv/config scripts/init-sheet.mjs dotenv_config_path=.env.local
```

از این لحظه، فرم ثبت‌نام مستقیماً روی همین شیت ردیف جدید اضافه می‌کند و
پنل‌های استاد/هنرجو همه‌چیز را زنده از همین شیت می‌خوانند. هر تغییری که
مستقیم داخل خود گوگل‌شیت هم بدهید (مثلاً افزودن جلسه یا لینک فایل در تب
`Files`)، بلافاصله در سایت دیده می‌شود.

**دادن دسترسی به هنرجو:** وقتی کسی فرم ثبت‌نام را پر می‌کند، یک کد ۴ رقمی
(PIN) به‌صورت خودکار ساخته و در ستون `pin` ذخیره می‌شود؛ همان لحظه در صفحه‌ی
«ثبت شد» هم نمایش داده می‌شود. همین کد را همراه شماره موبایلش به هنرجو
بدهید تا از `/login` وارد شود. (برای ارسال خودکار پیامک، در فایل
`app/api/register/route.js` محل مشخص‌شده را با سرویس پیامکی مثل کاوه‌نگار
یا ملی‌پیامک تکمیل کنید.)

## ۴) دیپلوی (تحویل نسخه‌ی واقعی به هنرجوها)

ساده‌ترین راه، [Vercel](https://vercel.com) است:

۱. این پوشه را در یک ریپازیتوری گیت‌هاب قرار دهید.
۲. در Vercel روی «Import Project» بزنید و ریپازیتوری را انتخاب کنید.
۳. همه‌ی مقادیر داخل `.env.local` را در تنظیمات Environment Variables پروژه در Vercel وارد کنید (`NEXTAUTH_URL` را به آدرس نهایی سایت تغییر دهید).
۴. Deploy بزنید. آدرس نهایی (مثلاً `https://nuance-piano.vercel.app`) را می‌توانید به هنرجوها بدهید.

---

## ۵) ساختار داده‌ها (برای مهاجرت آینده به Supabase)

هر تب گوگل‌شیت دقیقاً معادل یک جدول است — کافیست همین ستون‌ها را به‌عنوان
جدول در Supabase بسازید و `lib/googleSheets.js` را با کوئری‌های Supabase
جایگزین کنید؛ بقیه‌ی کد (API routeها و صفحات) بدون تغییر کار می‌کند چون فقط
با توابع `readSheet` / `appendRow` / `updateRowById` کار می‌کنند.

```
Students      id, fullName, phone, pin, age, city, level, goal, style, times, joined, remainingSessions, practiceAvg
Sessions      id, studentId, date, time, status
PracticeLogs  id, studentId, date, duration, note, fileUrl
Messages      id, studentId, from, text, time
Files         id, studentId, name, url, type
```

---

## نکات مهم

- **فایل‌های آموزشی:** چون سرویس ذخیره‌سازی فایل در این نسخه وصل نیست، ساده‌ترین راه این است که فایل را در Google Drive آپلود کنید، لینک اشتراک‌گذاری بگیرید و در تب `Files` گوگل‌شیت (ستون‌های `name` و `url`) اضافه کنید — بلافاصله در پنل هنرجو ظاهر می‌شود.
- **فایل صوتی/ویدیویی گزارش تمرین هنرجو:** در این نسخه فقط نام فایل ثبت می‌شود؛ برای آپلود واقعی باید یک سرویس ذخیره‌سازی (مثل Supabase Storage یا Google Drive API) اضافه شود — در صورت نیاز می‌توانم این بخش را هم تکمیل کنم.
- تم پیش‌فرض تیره است؛ با دکمه‌ی ماه/خورشید بالای صفحه به روشن تغییر می‌کند و انتخاب کاربر در مرورگرش ذخیره می‌شود. همین‌طور زبان با دکمه‌ی «Languages».
